NACA0012 / NACA4412
XFOIL REFERENCE SETUP AND PROVENANCE
====================================

PURPOSE
-------
XFOIL is used as an independent aerodynamic reference for comparison
with the OpenFOAM RANS calculations.

XFOIL is not treated as experimental truth.

This section documents:
1. geometry correspondence,
2. XFOIL numerical setup,
3. viscous and transition settings,
4. production polar generation,
5. panel-density sensitivity,
6. Cp-data provenance.

============================================================
GEOMETRY CORRESPONDENCE
============================================================

NACA0012
--------
Thickness ratio:
    t = 0.12

The closed/sharp trailing-edge thickness equation uses -0.1036.

A direct analytical comparison of the 481-point XFOIL source geometry
against the equation used by the OpenFOAM generator produced:

    maximum geometry discrepancy = 1.31e-10
    mean geometry discrepancy    = 2.71e-11

This is consistent with coordinate-output rounding.

The XFOIL and OpenFOAM NACA0012 geometries therefore represent the same
analytical sharp-TE airfoil definition.


NACA4412
--------
Parameters:
    m = 0.04
    p = 0.40
    t = 0.12

Thickness is applied normal to the standard NACA four-digit mean
camber line.

The XFOIL source geometry and the OpenFOAM reference-coordinate file
both contain 321 points.

Direct comparison gave:

    maximum |dx| = 0
    maximum |dy| = 0

The two source-coordinate arrays are exactly identical.

Therefore geometry mismatch is not a plausible explanation for
differences between the XFOIL and OpenFOAM aerodynamic predictions.

============================================================
PHYSICAL INTERPRETATION
============================================================

XFOIL and OpenFOAM do not solve identical aerodynamic models.

The production XFOIL calculations use XFOIL's coupled inviscid/
boundary-layer approach with transition prediction controlled by
Ncrit = 9.

The baseline OpenFOAM SST calculations use steady RANS with the
k-omega SST turbulence model.

Therefore disagreement between XFOIL and OpenFOAM must not
automatically be interpreted as numerical error.

Possible differences can arise from:
- turbulence and transition modelling,
- boundary-layer/separation treatment,
- numerical discretization,
- and limitations of each modelling approach.

XFOIL is therefore treated as a comparative reference, not as
experimental ground truth.
